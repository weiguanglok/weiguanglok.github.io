Inside the FPGA game

Display hardware

The game uses two Pmod OLEDrgb screens for animations and a scrolling seven-segment display on the Basys 3 board.

Turn-based combat

The game implements turn-based player-versus-player combat in hardware, with game logic written in Verilog and animations shown on the OLED screens.

LFSR randomness

The game uses a linear-feedback shift register (LFSR) to generate pseudorandom values for AI ability selection and parry mechanics.
