# Wei Guang Lok

Personal portfolio for electrical engineering, power systems and public transport.

## Preview before committing

Open index.html in a browser. The page, fonts, images and GSAP library are all local, so no installation or build is needed.

For an HTTP preview, run a static server in this directory, for example:

    npx --yes serve .

Open the URL printed by the server.

## Files

- index.html: portfolio content and links.
- styles.css: responsive layout, colours and typography.
- main.js: navigation and accessible motion.
- assets/: photographs, project screenshots, fonts and GSAP.

Rail power and rolling stock experience are presented as open editorial chapters, with dates, summaries and all contributions immediately available. Without JavaScript, the content and navigation links remain available. Reduced-motion preferences disable animated travel.
